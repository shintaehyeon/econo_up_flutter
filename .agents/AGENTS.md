# Econo-Up Project Customization Rules

## 1. API 명세 및 기획 준수 수칙 (API & Plan Adherence)
* **임의 구현 절대 금지**: 백엔드 API 명세서 및 기획서에 어긋나는 필드, 엔드포인트, 기능 등을 임의로 프론트엔드 코드에 추가하거나 백엔드 계약을 변형하지 마십시오.
* **목 데이터(Mock Data) 활용**: UI 디자인 시안(Figma 등)의 정합성 유지를 위해 아직 제공되지 않는 가상의 필드나 정보가 필요하다면, 절대 API 구조를 수정하지 말고 오직 프론트엔드 내의 로컬 목 데이터로만 구성하십시오.
